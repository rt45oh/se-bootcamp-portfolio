### สิ่งที่ฉันได้เรียนรู้มากที่สุด
- การคิดอย่างเป็นระบบผ่าน Flowchart และการเข้าใจ Workflow ของระบบ Version Control (Git) ซึ่งเป็นพื้นฐานสำคัญมาก ๆ ในการทำงานร่วมกันเป็นทีมในอนาคต

- การนำโครงสร้าง Logic ที่ซับซ้อน (เช่น Nested Loop หรือ Algorithm ยาก ๆ) ไปแปลงเป็นโค้ดโปรแกรมจริง และการจัดการกับ Git Conflict เวลาทำงานพร้อมกันหลายคน

- ฝึกเขียน Logic และแก้โจทย์ปัญหาคอมพิวเตอร์ให้หลากหลายมากขึ้น รวมถึงเริ่มศึกษา Library สำหรับทำเกมอย่าง Pygame และพื้นฐานการเชื่อมต่อ AI เบื้องต้น
